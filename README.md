# 📚 מערכת ניהול חנות ספרים וקופה

מערכת Web מתקדמת (Full-Stack) שנבנתה בטכנולוגיית **Blazor Server** ומיועדת לניהול מלא של חנות ספרים מקצה לקצה. המערכת מספקת פתרון הוליסטי הכולל קופה רושמת (POS), ניהול מלאי, עבודה מול ספקים, ודשבורד פיננסי לקבלת החלטות עסקיות.

## ✨ יכולות מרכזיות במערכת:
* 📊 **דשבורד פיננסי:** מעקב זמן-אמת אחר הכנסות, הוצאות ורווח נקי ברמה החודשית והשנתית, כולל גרפים והתראות חוסר במלאי.
* 🛒 **קופה חכמה (POS):** ניהול עגלת קניות, הפעלת הנחות, תמיכה במספר אמצעי תשלום ויצירת קבלות (כולל קישור לממשק תשלום).
* 📦 **ניהול קטלוג ומלאי:** ניהול רשימת הספרים, תמחור, מעקב כמויות מדויק ומערכת "ארכיון" להסתרת ספרים שאינם נמכרים יותר.
* 🏢 **רכש והחזרות (ספקים):** ניהול ספקים, יצירת הזמנות רכש/החזרה, עדכון מלאי אוטומטי בעת קבלת סחורה, ומחולל הודעות WhatsApp אוטומטי.
* 📜 **היסטוריית מכירות:** מעקב, סינון ועריכה של כלל העסקאות שבוצעו בחנות.

## 💻 טכנולוגיות
* **צד לקוח וצד שרת:** C#, .NET 8, Blazor Server
* **מסד נתונים:** Entity Framework Core (EF Core)
* **עיצוב וממשק:** HTML5, CSS3, עיצוב מותאם אישית (Custom UI)
